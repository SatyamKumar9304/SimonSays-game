🎮 Simon Says Game   --- 

A fun and interactive memory game built using HTML, CSS, and JavaScript. Test your memory by repeating the sequence of colors displayed by the game. Each level adds a new color to the sequence, 
making the game progressively more challenging.

✨ Features -

🎨 Interactive colored buttons
🧠 Memory-based gameplay
📈 Increasing difficulty with each level
⚡ Randomly generated color sequences
🎯 User input validation


🔄 Restart and replay by starting a new game

🛠️ Tech Stack
HTML5 — Structure of the game
CSS3 — Styling, layout, and button animations
JavaScript — Game logic, random sequence generation, and event handling

🎮 How to Play
Start the game using the start interaction implemented in the game.
Watch the color button that flashes.
Repeat the sequence by clicking the buttons in the same order.
Each successful round adds another color to the sequence.
One incorrect click ends the current round.

Try to beat your highest level!
